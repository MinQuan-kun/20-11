# 💐 Website Bó Hoa & Bức Thư Tri Ân 20/11

Dự án tách biệt hoàn toàn dành riêng cho ngày Nhà Giáo Việt Nam 20/11:
- **Concept**: Một bó hoa nghệ thuật rực rỡ xuất hiện ở trung tâm, nhấp vào bó hoa sẽ mở ra bức thư tri ân trang trọng.
- **Tối giản & Trực quan**: Không cần bước nhập tên, người xem có thể mở ngay thư chúc mừng.
- **Hiệu ứng**: Cánh hoa hồng bay nhẹ nhàng trên nền, pháo sáng lấp lánh khi mở thiệp và nhạc nền du dương.

## 📂 Cấu trúc thư mục
```
20-11-bouquet/
├── index.html          # Trang chính hiển thị bó hoa & modal thư
├── favicon.ico         # Icon biểu tượng trên tab
├── css/
│   └── style.css       # Toàn bộ hiệu ứng, layout, phong thư vintage
├── js/
│   └── script.js       # Xử lý tương tác mở thư, cánh hoa bay, âm thanh
└── audio/
    └── bg-music.mp3    # Nhạc nền tri ân
```

## 🚀 Trải nghiệm ngay
Mở file `index.html` trực tiếp bằng trình duyệt hoặc thông qua server local tại:
👉 `http://localhost:8030/`
